# 05. MagicSquare Agent Code Reviewer Setup Report

## 개요
- 목적: 코드 리뷰 전용 에이전트(`code-reviewer`)를 생성하고, 보고서 내보내기/프롬프트 저장 기능을 지침에 반영
- 범위: `.cursor/agents` 및 `prompt` 설정 파일 작성
- 결과: 에이전트 파일 1개 생성, 프롬프트 파일 2개(기존 1개 + 05번 통합 저장본 1개) 확보

## 작업 내역
1. `code-reviewer` 에이전트 파일 생성
   - 파일: `.cursor/agents/code-reviewer.md`
   - YAML frontmatter 추가:
     - `name: code-reviewer`
     - `description: 버그, 규칙 준수, 성능 개선을 점검하는 전문 코드 리뷰어`
     - `model: inherit`
     - `readonly: true`
   - 본문에 코드 리뷰 지침(버그/규칙/성능 중심) 작성

2. 보고서 내보내기/프롬프트 저장 지침 보강
   - 파일: `.cursor/agents/code-reviewer.md`
   - 추가 섹션:
     - `## 보고서 내보내기`
     - `## 프롬프트 저장`
   - 내보내기 가능한 Markdown 보고서 구조 및 Saved Prompt 포함 규칙 명시

3. 재사용 프롬프트 저장
   - 파일: `prompt/code-reviewer.saved-prompt.md`
   - 코드 리뷰 실행용 표준 프롬프트 저장

## 산출물
- `.cursor/agents/code-reviewer.md`
- `prompt/code-reviewer.saved-prompt.md`
- `prompt/05.code-reviewer.full-prompts.md`
- `Report/05.MagicSquare_Agent_CodeReviewer_Setup_Report.md`

## 검증
- 파일 생성/수정 상태 확인 완료
- `code-reviewer` 에이전트가 요구한 속성(`model: inherit`, `readonly: true`)을 포함하는지 확인 완료
- 보고서 내보내기 및 프롬프트 저장 규칙이 에이전트 지침에 반영되었는지 확인 완료

## 후속 제안
- 필요 시 `05` 프롬프트를 기반으로 팀 표준(MagicSquare 용어/ID) 템플릿으로 확장 가능
- 리뷰 결과 자동 파일 저장 규칙(예: `Report/reviews/*.md`)을 추가하면 운영 일관성 향상 가능
