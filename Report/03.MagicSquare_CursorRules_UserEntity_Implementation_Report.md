## 3. `.cursorrules` 확정 구조

### 3.1 최상위 섹션

| 키 | 역할 |
|----|------|
| `project` | 목적, 도메인 요약, SSOT 문서, 레이어별 커버리지 목표 |
| `code_style` | Python 3.10+, PEP 8, Black 88열, type hints, Google docstring |
| `architecture` | ECB 3레이어 + data 보조, 의존 방향 DEP-01~04 |
| `tdd_rules` | Dual-Track TDD, RED/GREEN/REFACTOR, DT/UT/ST/IT RED 순서 |
| `testing` | pytest, AAA, `test_` 접두사, fixture scope, 마커 |
| `forbidden` | pattern / reason / alternative 구조 |
| `file_structure` | `src/magic_square/{entity,boundary,control,data}/`, `tests/` 트리 |
| `ai_behavior` | 코딩 전·중·후 규칙, TDD 위반 시 경고 템플릿 |

### 3.2 TDD phase (요약)

| Phase | 핵심 |
|-------|------|
| **RED** | 설계서 Test ID 대응 failing test → `pytest` 실패 확인 |
| **GREEN** | 최소 구현만; 리팩터·다음 TC 선행 금지 |
| **REFACTOR** | 계약 불변; 스위트 green + 커버리지 유지/상승 |

### 3.3 검토 시 식별된 주의점 (미수정·기록만)

- `architecture.key_components` YAML 계층이 의도와 다르게 파싱될 수 있음 → 이후 `layers` 구조로 정리됨.
- `tdd_rules`의 stub/bootstrap vs `forbidden`의 “RED 없이 src 수정” 해석 경계는 운영 시 명시 필요.
- Cursor가 `.cursorrules` YAML을 스키마로 강제하지 않을 수 있음 → 규칙은 평문 지시로도 읽힘.

## 4. ECB · User Entity 구현

### 4.1 배치

| 항목 | 경로 |
|------|------|
| 패키지 | `src/magic_square/` |
| Entity | `src/magic_square/entity/user.py` |
| 공개 export | `src/magic_square/entity/__init__.py` → `User` |
| 테스트 | `tests/entity/test_user.py` |

**의존성:** `entity`는 `boundary` / `control` / `data` / I/O를 import하지 않음 (DEP-01 준수).

### 4.2 `User` 도메인 규칙

| 규칙 ID | 내용 | 검증 시점 |
|---------|------|-----------|
| U-01 | `user_id` > 0 | `__post_init__` / `create` |
| U-02 | `username` 공백·trim 후 비어 있지 않음 | 생성·`rename` |
| U-03 | `email` 기본 형식 (`@`, 도메인) | 생성·`change_email` |
| U-04 | `create` 시 `is_active == True` | `create` |
| U-05 | `deactivate` 시 `is_active == False` | `deactivate` |

### 4.3 공개 API

| 메서드 | 설명 |
|--------|------|
| `User.create(user_id, username, email)` | 검증된 활성 사용자 생성 |
| `rename(new_username)` | 사용자명 변경 |
| `change_email(new_email)` | 이메일 변경 |
| `deactivate()` | 비활성화 |

**코딩 규칙 준수:** `from __future__ import annotations`, 전 메서드 type hints, public API Google docstring, `@dataclass(slots=True)`.
