## 1. 목적

단일 `.cursorrules` 중심 운영에서, 규칙을 관심사별 `.cursor/rules/*.mdc`로 분리하여
유지보수성과 적용 정확도를 높인다.

---

## 2. 수행 내용

### 2.1 생성된 분리 규칙 파일

| 파일 | 역할 | 적용 범위 |
|------|------|-----------|
| `.cursor/rules/magicsquare-project.mdc` | 프로젝트 공통 원칙, SSOT | `alwaysApply: true` |
| `.cursor/rules/magicsquare-python-code-style.mdc` | Python 스타일, 타입힌트, docstring | `**/*.py` |
| `.cursor/rules/magicsquare-ecb-architecture.mdc` | ECB 레이어 책임/의존 방향 | `src/magic_square/**/*.py` |
| `.cursor/rules/magicsquare-tdd-testing.mdc` | Dual-Track TDD, pytest AAA | `{tests/**/*.py,src/**/*.py}` |
| `.cursor/rules/magicsquare-forbidden.mdc` | 금지 패턴 규정 | `**/*.py` + `alwaysApply: true` |

### 2.2 운영 결정

- 사용자 선택: **옵션 1**
  - `.cursorrules`는 기존 상태 유지
  - 실제 운영은 `.cursor/rules/*.mdc` 우선

## 3. 운영 방식 (확정)

1. 전역 원칙: `magicsquare-project.mdc`
2. 코드 작성 시: `magicsquare-python-code-style.mdc`
3. 아키텍처 작업 시: `magicsquare-ecb-architecture.mdc`
4. 테스트/구현 흐름: `magicsquare-tdd-testing.mdc`
5. 금지사항 검증: `magicsquare-forbidden.mdc`

## 4. 기대 효과
