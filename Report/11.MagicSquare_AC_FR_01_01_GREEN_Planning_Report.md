1. **입력 오름차순:** `None` → `[]` → `[[]]*4` → `3×4` (`AC_FR_01_01_PARAM_GRIDS` 순서)
2. **검증 깊이:** `code` → `message` → `FailureResult` 형태 → `resolve()` 격리 → 메시지 문자 일치 → parametrize

### 3.2 G1 제외·이미 GREEN (16건)
