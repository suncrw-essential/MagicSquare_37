## 3. 계약 정의 (AC-FR-01-01)

본 Track A RED는 README·학습 체크리스트와 정렬된 **학습용 오류 계약**을 사용한다.

| 필드 | 값 |
|------|-----|
| `code` | `INVALID_SIZE` |
| `message` | `Grid must be 4x4.` |
| Layer | Boundary |
| Domain `resolve()` | **호출 금지** (0회) |

> **참고:** `docs/PRD_MagicSquare.md` 공식 코드는 `ERR_GRID_ROWS` / `Grid must have exactly 4 rows.` 이다. GREEN 단계에서 PRD 정합으로 통합할지, 학습용 `INVALID_SIZE`를 유지할지 Decision Needed.

## 10. GREEN 단계 권장 작업

1. `ScreenBoundary.solve()`에 BR-01 행 수 검증 추가 (`len(grid) != 4` 및 `grid is None` 처리).
2. 실패 시 `FailureResult(code="INVALID_SIZE", message="Grid must be 4x4.")` 반환.
3. 검증 실패 분기에서 **`resolve()` 호출 제거**.
4. 26건 RED 테스트 GREEN 확인 후 REFACTOR (validator 분리 등).
5. PRD `ERR_GRID_ROWS`와 학습용 `INVALID_SIZE` 정책 통일 여부 결정.
