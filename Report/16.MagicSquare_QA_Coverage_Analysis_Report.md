
### 2.3 Step 1 — Dual-Track 커버리지 (SSOT vs 유효 경로)

프롬프트 SSOT는 `--cov=src/entity` 등이나, 패키지 루트는 `src/magic_square/`이다. 본 보고서는 **동일 테스트 집합**에 대해 유효 경로로 재측정한다.

```bash
# Domain Track (NFR-01)
python -m pytest tests/entity/ \
  --cov=src/magic_square/entity --cov-report=term-missing

# Boundary Track (NFR-02)
python -m pytest tests/boundary/ \
  --cov=src/magic_square/boundary --cov-report=term-missing

# Global (NFR-03)
python -m pytest --ignore=tests/control \
  --cov=src --cov-report=term-missing
```
