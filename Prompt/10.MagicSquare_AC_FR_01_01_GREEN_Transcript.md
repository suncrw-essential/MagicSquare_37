## Turn 2 — pytest 실행 오류

**User 요청 요약**

```text
python -m pytest tests/boundary/test_ac_fr_01_01_invalid_size.py:TestAcFr0101NormalFailureReturn::test_none_grid_returns_failure_with_invalid_size_code -v
```

→ `ERROR: file or directory not found`

**Assistant 결과 요약**

**원인 2가지:**

1. **구분자:** `.py` 뒤는 `:` 한 개가 아니라 **`::` 두 개**
   - 잘못: `file.py:Class::test` → 전체 문자열을 파일 경로로 해석
   - 올바름: `file.py::Class::test`

2. **함수명:** 실제 정의는 `test_none_grid_returns_failure_invalid_size_code` (`with_invalid` 없음)

**올바른 명령:**

```powershell
python -m pytest tests/boundary/test_ac_fr_01_01_invalid_size.py::TestAcFr0101NormalFailureReturn::test_none_grid_returns_failure_invalid_size_code -v
```
